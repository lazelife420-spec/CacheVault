# Cache Vault Founder MVP v0.1.3

**Cache Vault Founder Edition** — local-first clipboard vault with offline Founder unlock.

## Free (always usable)

- Capture, search, favorites, copy back out
- Local-only vault storage
- Single-item export (TXT/MD/HTML/JSON)
- Stamped Receipts viewing

## Founder unlock ($19 lifetime, manual license)

- Advanced exports and ZIP bundles
- Proof-pack exports
- HTML bundles and editable copy workflows
- Vault Macros and custom Safes
- Advanced review filters

## Install license

1. Open Cache Vault → sidebar **Founder**
2. **Import License File** or **Enter License**
3. License stored at `%LOCALAPPDATA%\CacheVault\license.json`

See `docs/FOUNDER_PURCHASE_AND_LICENSE.md` in the repo for full instructions.

## Trust

- **Local-only** — no cloud sync, no accounts, no telemetry
- **No mobile bridge claim** in this Founder MVP SKU
- **Offline license verification** — Ed25519 public-key check only
- **Manual license delivery** — no license server in this MVP
- Windows executable is **unsigned**; verify SHA256 before running
