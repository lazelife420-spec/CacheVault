## Minimum Permissions Target

To respect user privacy, avoid security warnings, and comply with **The Proof Foundry** honest positioning, the MVP must request only:

```json
{
  "manifest_version": 3,
  "name": "Cache Vault Companion",
  "version": "0.1.0",
  "permissions": [
    "activeTab",
    "scripting",
    "clipboardWrite",
    "storage"
  ]
}
```

### Avoid (Out of Scope / Prohibited):
- `history`: Never request browser history access.
- `declarativeNetRequest` / Broad Hosts: Do not intercept network traffic.
- Background scraping: No background page scraping or tabs monitoring.

## Smallest Safe MVP Plan

### 1. Pairing & Authentication Bridge
- Extension stores a pairing token in local extension `chrome.storage.local`.
- Cache Vault Desktop provides a paired token in the UI settings (or a pairing button).
- Extension sends capture requests to `http://127.0.0.1:5000/api/mobile_share` or similar capture endpoint.

### 2. Popup UI & Actions
- **Collect Links:** Triggers link script injection on the current active tab.
- **List View:** Shows a simple table/list of extracted links with checkboxes.
- **Copy Actions:**
  - Copy as Plain List
  - Copy as Markdown
  - Copy as Numbered List
- **Send to Vault:** Transmit selected link batch to Cache Vault Desktop.

### 3. Link Extraction Script
- Minimal content script executed dynamically on the current tab:
  ```javascript
  const links = Array.from(document.querySelectorAll('a'))
    .map(a => ({ url: a.href, title: a.innerText.trim() }))
    .filter(l => l.url.startsWith('http'));
  ```
