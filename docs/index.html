FAQ

Short answers for the questions buyers usually have before they download or pay.

Is the free version actually usable?

Yes. Free covers the daily vault workflow: capture, search, favorites, copy back out, and single-item export. Founder unlocks advanced proof and organization workflows.

Does Cache Vault require a cloud account?

No. The current product is local-first. No account, no subscription, and no cloud requirement for the core vault.

Is this Windows only?

Yes for the public desktop release shown on this page. The current downloadable build is a Windows ZIP package.

What do I get with Founder?

Founder unlocks proof-pack exports, bulk ZIP bundles, HTML bundles, editable copy workflows, Snippet Macros, custom Safes, and advanced review filters.

How is the license delivered?

Founder licenses are delivered manually during the MVP period. After purchase, you receive install/import instructions and a signed license.json.

Can I keep using the free version?

Yes. The free version remains usable. Founder is an upgrade path for advanced workflows, not a forced subscription gate.

What does local-first mean here?

Your vault stays on your PC. This build does not require a cloud account and does not depend on a license server to stay unlocked.

Is the app code-signed?

No. The release notes explicitly state that the Windows executable is currently unsigned, so SmartScreen may warn. Verify the ZIP checksum before running it.

How do I verify the SHA256?

Download the ZIP, run Get-FileHash .\CacheVault-v0.1.6-windows.zip -Algorithm SHA256 in PowerShell, and compare the result with the published SHA256SUMS.txt.
