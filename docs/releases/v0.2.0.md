# Cache Vault v0.2.0

Cache Vault v0.2.0 is a product-generation release: a unified desktop shell and page-template architecture, and the first authoritative Mobile Access lifecycle with a version/protocol compatibility handshake between desktop and the Android companion. Also the first CacheVault Mobile build signed with a dedicated, permanently-retained production release key (every prior build used the shared Android debug key).

Proof (from the live GitHub Release body, `gh release view v0.2.0`):
- Desktop and Android versions aligned at v0.2.0
- Validated against an isolated large QA vault (~1,950 items): Edit Clip Text 10/10 passed (5 human-paced, 5 rapid), Combined Preview 5/5 passed, Settings navigation 5/5 passed, 0 Windows "Not Responding" events, 0 blank-list flashes, 0 stale-inspector incidents, 0 stuck dialog grabs
- Real device verification: Galaxy S23 pairing, phone-to-desktop clip transfer, desktop device-identity display, Update-required UI, disabled-bridge send-blocking, re-enable/reconnect
- Released via `gh release create` with 3 public assets
