# Cache Vault v0.1.3-rc4 (release candidate)

**Status:** Release candidate — not a final release. **No git tag.** Do not replace the shipped **v0.1.2** desktop release.

**Source commit:** `feature/cache-vault-luxury-ui-mobile-inbox` after mobile pairing blocker fix (`610fb38`).

## Two-part RC4 candidate

```text
Desktop RC4 = luxury vault UI + Mobile Inbox receiver
Android RC4 = Simple Mode Share Sheet + Manual Setup + Send to PC
```

### Desktop (Windows exe in this zip)

Everything in **v0.1.3-rc3**, plus:

| Area | Status |
|------|--------|
| Luxury vault UI polish | Done |
| Command Center / graphite palette | Done |
| **Mobile Inbox** screen — items sent from paired phone | Done |
| Paired mobile **Send-to-PC** endpoint (`POST /mobile/v1/inbox/send`) | Done |
| Receipt-backed mobile inbox item creation | Done |
| Default Safe assignment from mobile send | Done |
| Vault Macros live execution (from rc3) | Done |

### Mobile companion (Android debug APK — separate artifact)

Requires **Mobile Access ON** on the PC running this build:

- **Manual Setup** — host, port, device ID, pairing code; validates against desktop bridge
- **Simple Mode** from Android Share Sheet — large buttons, plain labels
- **Send to PC** — creates desktop Mobile Inbox item with `capture_mode=mobile_share`
- Read-only LAN bridge browse on port **8742** (status, clips, recently-removed)
- Safe metadata in clip payloads when present

The Android APK bundled with this RC is a **debug/internal proof artifact**, not a signed production Play Store release.

## Honest limitations (not claimed in this RC)

- **No cloud sync** — paired local Wi-Fi bridge only
- **Safes are not encrypted** — organizational metadata only
- **Image/file send from Share Sheet** — deferred
- **Sensitive warn-before-send** — deferred/planned
- **Simple Mode** is not labeled “old person mode” or similar
- Android APK is debug/internal candidate only
