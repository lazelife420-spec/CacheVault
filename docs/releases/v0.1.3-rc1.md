# Cache Vault v0.1.3-rc1 (release candidate)

**Status:** Release candidate — not a final release. **No git tag.** Do not replace the shipped **v0.1.2** desktop release.

## Scope split (truthful)

### Desktop (Windows exe in this zip)

Everything in **v0.1.2** desktop scope, plus packaging built from the mobile companion branch:

- Local-only clipboard vault, tray, settings, filters, sensitive auto-expiry
- Window/tray branding unchanged from v0.1.2 line
- **Not** a retag or mutation of `CacheVault-v0.1.2-windows.zip`

### Mobile companion (Android app — separate artifact)

Requires **Mobile Access ON** on the PC running this build:

- Read-only LAN bridge on port **8742**
- Pairing, vault browse, image thumbnails, proof/settings screens
- **Fix in this RC:** `GET /mobile/v1/recently-removed` no longer blocked by route guard (`remove` substring false positive)

Install the matching debug/release APK from the same branch build; it is **not** inside this Windows zip.
